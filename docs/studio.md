# 100-idea studio

All 100 brainstormed ideas have an interactive interpretation at /experiments/studio, reached from Projects, Experiments, and the footer. This is a prototype collection for trying and curating the ideas, not a claim that 100 independent production systems or physically accurate 3D simulations have shipped. The main navigation remains Projects, Experiments, CV, and the identity remains live typography.

## What works

- 100 selectable SVG compositions across ten collections; direct study links use ?study=1 through ?study=100.
- Drag and keyboard control, meaningful scene parameters, seeded remix, palette choices, bounded 40-state undo/redo, reset, manual advance, and optional playback.
- Favorites, per-study compositions, and a real-project shortlist persist locally; a text export contains the actual saved studies and disclosed project contribution.
- Complete validated composition links, SVG downloads, and real 1600×960 PNG exports. The project-image mosaic embeds its image when exporting.
- A real bounded Conway automaton; procedural interference, branching, contour, and orbital studies. Other physics/material effects are illustrative SVG models rather than simulation engines.
- Project evidence uses the supplied portfolio content. Career history, qualifications, and additional work remain unfilled.
- A printable evidence sheet, real architecture/contribution links, reading-interest lenses, local turn-taking, two-player keyboard controls, and an opt-in Web Audio instrument.
- Playback pauses offscreen/when the tab is hidden, starts only after Play, and is disabled by system or manual reduced motion. Sound starts only after Enable sound.

## Interpretation boundaries

The ambitious original ideas are intentionally presented as experiments that can be evaluated before deeper engineering:

- Fold, cloth, liquid, gravity, spring, holographic, glass, and erosion studies are parameterized visual interpretations, not physically accurate simulations or photorealistic renderers.
- The darkroom is a graphic exposure study, the type mosaic uses a real screenshot, and the miniature interface links to the working project.
- Decision bars demonstrate hypothetical priorities; they are explicitly not measured performance, delivery estimates, or project metrics. The sample broken layout is isolated from the actual site.
- CV maps use documented project milestones and implementation evidence while personal career details are pending. Reading lenses do not assert new personal skills.
- Ideas 81–90 operate on one device. There are no fabricated visitors, public submissions, moderation, real-time synchronization, remote voting, or community counts. Publishing them as shared services would require storage, abuse controls, moderation, and a deployment choice.
- Different-day composition seeds use the visitor's local calendar date. Browser instrument sound is short, quiet, optional, and never persisted.
- The global ribbon changes shape across the three sections. Full cinematic page transitions, GPU 3D environments, live collaborative services, and integrations with real career data remain future expansions, not completed features.

## Review or remove ideas

Use Save study to create a local exhibition, then the Saved studies filter to review it. Each numbered scene is independent in src/components/studio-scene.jsx and its catalog record is in src/lib/studio.js. Keep IDs stable for shared links; retain the distinction between actual evidence and hypothetical samples. Saved data uses localStorage key jw-creative-studio-v1; deleting that key removes local studio data. No data is sent to a service.
